DECISIONS

  • DECISION 01

    Micro-Agent Architecture

    Separated LLM capabilities into modular agents (EDA, Leakage, Sanity, Feature, Reflection) for parallel execution and debuggability.

  • DECISION 02

    Hybrid Optimization

    Leveraged LLMs strictly for qualitative decisions while using Genetic Algorithms for exact, quantitative hyperparameter tuning.

  • DECISION 03

    Terminal-Native TUI

    Built using Textual and Plotext to offer developers immediate, lightweight accessibility without managing frontend/backend server states.

  • DECISION 04

    Async Orchestration

    Parallelized agent execution using asyncio to drastically reduce processing bottlenecks during feature extraction.
