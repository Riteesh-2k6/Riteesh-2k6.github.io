DEEPHIRE

AI INTERVIEW INTELLIGENCE PLATFORM

DeepHire runs technical mock interviews end to end. It draws questions from a curated SQLite bank or generates fresh ones through Groq, asks them one at a time, and scores every answer with an LLM in about a second. When the API fails, the interview keeps going.

DECISIONS

  • DECISION 01

    Hybrid Question Generation

    Mixing SQLite DB retrieval with the Groq API ensures both reliability and unpredictability in question sets.

  • DECISION 02

    Mixtral-8x7b via Groq

    Chosen for high-speed inference and excellent instruction-following capabilities for structured JSON output.

  • DECISION 03

    Session-based State Management

    Flask sessions handle interview progression securely without persisting incomplete runs to the database.

  • DECISION 04

    Graceful Degradation

    Implemented fallback mechanisms in SmartSelector if the Groq API fails or times out during generation.
